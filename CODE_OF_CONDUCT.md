# Code of conduct

Be respectful, specific, and constructive. Critique methods and evidence without personal attacks. Welcome questions and corrections from people with different backgrounds and experience.

Harassment, discrimination, threats, deliberate disclosure of private information, and abusive conduct are not acceptable. Maintainers may remove offending content, close discussions, or restrict participation to protect the community. Decisions should be proportionate and explained where doing so does not expose private information.

Raise ordinary technical concerns through GitHub issues. Use GitHub's private reporting or abuse-reporting mechanisms for sensitive conduct concerns rather than posting personal information publicly.
