# AeroVLA reproduction: verified capabilities and limits

This snapshot contains implementation code and a reduced capability summary. It excludes private execution diagnostics, raw logs, machine inventories, experiment configurations and complete artifact bundles. The video hashes listed in the publication manifest are review candidates; no video is included or published by this snapshot.

| Phase | Verified capability | Limit that remains |
|---|---|---|
| P01 | Runtime import checks, dependency consistency, a real BF16 CUDA operation and the Vulkan graphics prerequisite passed. | This dated readiness check did not exercise navigation or training, and stop/resume persistence was not tested. [Runtime probe](scripts/runtime_probe.py). |
| P02 | Pinned asset integrity/extraction checks and the required files for one selected ModernCityMap demo passed. | This selected scope does not certify every bundled map, unseen-scene generalization or expert-label semantics. [Asset validator](scripts/prepare_assets.py). |
| P05 | Three genuine recorded front/down observation pairs produced outputs that passed strict action parsing. | Outputs were not applied to a vehicle; this does not measure flight success or expert-action accuracy. [Offline inference probe](scripts/offline_policy_probe.py). |
| P03 | The explicitly named timed-reset candidate passed two actual reset/capture checks at the unchanged 0.1 m and 0.05 rad tolerances. | Earlier reset variants failed. The candidate changes reset behavior and must retain a separate runtime identity. [Reset protocol](docs/runbooks/reset_protocol.md). |
| P04 | Three separate scripted heading, horizontal and vertical probes passed with the timed-reset candidate. | These bounded probes do not establish general navigation performance. [Probe implementation](scripts/simulator_probe.py). |
| P06 | One declared demonstration completed 15 linked policy/action cycles and 16 observations, with the upstream navigation-success outcome. | This earlier trace used the original reset, whose reset prerequisites had failed; it is not a frozen baseline or proof of physical touchdown. [Evidence hooks](scripts/_aerovla_runtime_hooks.py), [evaluation accounting](docs/runbooks/evaluation.md). |
| P07 | A controlled interruption after two completed actions retained an unscored partial. A separate fresh attempt completed 15 actions and reported upstream navigation success. | This is a fresh attempt, not physics-state resumption or learned recovery. The historical pair does not isolate recording cost. A separately named supplement measures direct recording components; it does not establish the effect of logging on flight outcome. [Interruption contract](docs/runbooks/interruption.md), [restart validation](docs/runbooks/restart_validation.md). |
| P08 | All 20 frozen development trials produced valid outcomes, with upstream success on 6/20 and oracle success on 7/20. No extra, missing or retried trial was reported. | This is a small same-map development baseline using the separately identified timed-reset runtime; it is not a holdout result or an adaptation improvement. [Evaluation accounting](docs/runbooks/evaluation.md). |
| P10 | One real optimizer update produced finite gradients and changed all 454 intended LoRA/projector tensors. A separate save/unload/reload lifecycle matched the fixed teacher-forced comparison exactly. | Five published examples were preflighted, but only one received the optimizer update. Fixed comparison loss increased from 0.480681 to 0.486200; no useful learning or navigation improvement is established. [Training contract](docs/runbooks/training.md), [published-reference contract](docs/runbooks/published_reference.md). |

P09 expert correction is incomplete. Published reference membership does not establish expert or recovery correctness, physical action horizon or independent physical action frame. The narrow `published-reference-mechanics` mode permits P10's single update only; P12 rejects it. No holdout-based checkpoint selection, recovery-label generation or completed adaptation claim is made.

The implementation preserves the pinned [AeroVLA source](https://github.com/XuPeng23/AeroVLA/tree/e37685afb8953d1f5a09155d7255960cee1bfd9d) and explicitly distinguishes changed execution behavior from original model weights. The released task uses benchmark target information and a navigation stopping criterion. It is not a demonstrated autonomous physical landing system.

Source-copy hashes in [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json) identify the reviewed bytes. They do not assert that every changed file was executed. [REVIEW.md](REVIEW.md) describes the candidate's exclusions, review coverage and remaining publication decision.
